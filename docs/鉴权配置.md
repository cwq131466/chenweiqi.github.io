一、确保交换机与鉴权服务器之间`ip`可达

二、查看交换机是否已经配置`RADIUS`方案，并进行配置

```c++
display radius scheme     // 查看所有已经配置的RADIUS方案
display radius statics    // 查看与RADIUS服务器交互的统计信息
display domain      // 查看所有域配置，及其应用的认证方案
```

三、创建或配置`RADIUS`方案，假设已有方案为`rad1`

```c++
radius scheme rad1           // 进入rad1配置
primary authentication XXX.XXX.XXX.XXX 1812 key simple/cipher 密码      // 配置主认证服务器IP、端口、密钥（明或密显示）
primary accounting XXX.XXX.XXX.XXX key simple/cipher 密码 // 配置主计费服务器IP、端口、密钥（明或密显示）
quit  // 退出
```

四、全局启用`802.1X`

```c++
dot1x   // 全局启用dot1x
```

五、在用户接入端口开启`dot1x`

```C++
interface g0/0/1      // 进入相应接口
dot1x   // 开启dot1x
dot1x port-method portbased  // 基于端口进行认证
dot1x port-method macbased   // 基于MAC进行认证
```
